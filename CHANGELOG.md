# Change Log

## binarytree 0.0.3

* Added `version` property to tell the version of this library;
* Added moved CI to GitHub, including workflows to:
    * test `binarytree`
    * publish `binarytree` to GitHub Release
    * publish `binarytree` to LuaRocks
* Removed dependencies for code coverage. Now, only `busted` and `luacov` are required to run code coverage;
* Refactored docs in many places.

## binarytree 0.0.2

* Added `find(value)` method to the binary tree. See [Find](#find) for more information.

## binarytree 0.0.1

* Initial release.
